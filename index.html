METHODS

How this portal is built

The interface is a presentation layer over precomputed bibliometric, network and machine-learning outputs.

01

Bibliometric corpus

PubMed-derived publication metadata, authorship, MeSH and keyword information.

02

Semantic analysis

Abstract embeddings, dimensionality reduction and clustering provide a navigable scientific map.

03

Network analysis

Coauthorship and multidimensional graph outputs describe collaboration and scientific proximity.

ARCHITECTURE

No runtime analytics backend required

All heavy computation is performed in the notebook. This website only reads precomputed CSV, JSON and GEXF outputs and renders them in the browser, which makes GitHub Pages an appropriate deployment target.
